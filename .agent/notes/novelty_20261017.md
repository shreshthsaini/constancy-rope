# Research target and current novelty boundary

User clarification, October 17, 2026: deliver a genuinely novel method with
performance close to or better than recent state of the art. A negative working
report and small improvements to established controls do not complete this goal.
The current domain remains training-free resolution extrapolation of frozen DiTs.
Neither novelty nor competitive efficacy has been established for Constancy RoPE.

## Effect on the active campaign

CR14's RMS controls and lag correction remain diagnostic experiments, with the
original methods, scores, and gate unchanged. None is currently a defensible main
novel contribution. Preserve all outcomes. Do not launch the 64-prompt confirmation
solely because one of these controls passes its development gate. The fresh set
remains unused until the method, novelty distinction, baselines, and analysis
protocol are fixed. The prepared confirmation code currently accepts only the
CR14 candidates; a genuinely new method requires an explicit new protocol and
corresponding validation, not silently adding it to an old selection file.

## Concrete next research question

Existing probes do not establish a universal positive map from an attention
frequency gain to generated image power. Those probes used joint-axis changes
on NTK2, so they cannot identify SEGA's response. CR14 isolates simpler scalar
and timing explanations but cannot by itself establish a new mechanism.

Investigate whether resolution failures are caused partly by *uncontrollable
spectral errors*: a controller observes an error that its allowed attention
changes cannot correct, or corrects it with the wrong sign. The immediate task
is an axis-separated response measurement at the actual SEGA operating point.
Use identical intermediate latent, text embeddings, noise time, and model state
for positive and negative interventions; preserve and restore all hooks/history.
Do not compare different sampling trajectories as if they were local derivatives.

A candidate mechanism, still unvalidated, would project spectral discrepancies
onto the locally reachable subspace before applying a bounded correction:

    J[b,j] = derivative of spectral statistic b with respect to control j
    delta = argmin ||W^(1/2) (J delta - e)||^2 + lambda ||delta||^2
            subject to a trust region and a scalar-gain preservation constraint

The candidate must demonstrate that off-diagonal response and sign information
matter, and that rejecting unreachable corrections preserves structure or detail.
This is a hypothesis, not a novelty claim. Finite differences, least squares,
trust regions, projection, and control theory are established tools. A new name
or their assembly is not sufficient. The possible contribution is a validated
resolution-specific failure mechanism and a practical intervention that existing
SEGA, SCG, entropy, and receptive-field methods do not implement. Confirm this
against their full algorithms and code before promoting it.

Critical risks: response changes by prompt, time, axis, and layer; calibration
may not transfer; extra forward calls may erase practical value; matching spectral
power may improve the proxy while harming semantics. The global native target
can also be wrong for a particular scene. If the response measurement does not
predict held-aside interventions, do not build a larger controller on it.

## Evidence needed for a competitive method

1. Establish the mechanism in development/calibration data, independently of a
   preferred outcome. Compare full response, diagonal response, sign-free response,
   and existing controls at matched cost. Stop branches unsupported by these tests.
2. Pin and validate current compatible baselines, especially SEGA, AReA, UltraImage,
   TIDE, and DyPE. Include HRDiT when comparing the quality/efficiency frontier.
   Check official model, schedule, and scoring conventions before pooling numbers.
3. Compare the same checkpoint, captions, seeds, resolution, hardware, and measured
   end-to-end runtime. Extra calibration/probe passes count toward cost. A winning
   older-backbone comparison is not a claim to beat every current image generator.
4. Freeze a practical noninferiority margin before confirmation if claiming
   "close to SOTA". A nonsignificant difference or overlapping intervals is not
   equivalence. Preserve preference, semantics, crop quality, and latency tradeoffs.
5. Use fresh prompts for confirmation, then seed replication, another resolution,
   and another backbone if the first result warrants it. Add blinded human
   comparisons before strong perceptual superiority claims. The existing 64 prompts
   are one bounded confirmation stage, not a complete SOTA benchmark.

Maintain the working paper as an evidence record. Write the final methods-paper
claim only after the mechanism and competitive result are supported.
