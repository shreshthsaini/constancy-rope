## Sources and caveats

- **a1 (a) Constancy gate activity, late-profile target (held-out constancy, ntk2 base).** Source: `out_krea/main/constancy/4096x4096/*.json` rows 8-48; dev: `out_krea/pilot/constancy`. Field `gains[t].controller_log_g` minus its step-0 value (= log tau, checked); `gains[t].sigma`; anchor gate from `gains[t].bins[*].anchor_count`. Caveats: Only 41 held-out prompts exist for this run (rows 8-48; the ntk2-base constancy main run was stopped early); seed 0. Onset index = number of leading uncorrected steps. The correction stays exactly zero until an anchor band (wavelength 16-64 tokens) passes the w > 0.5 gate; temp_only is exactly zero. Corrects the note 'acts only at sigma <= 0.35 (steps 24-27)': onset is steps 16-22 (sigma 0.70-0.46) held-out and 19-22 on dev.
- **a2 (a) Constancy_tm gate activity (held-out, released SEGA base, sref temperature).** Source: `out_krea/mainsb/constancy_tm/4096x4096/*.json` rows 8-194; dev check `out_krea/devtm_eta1/constancy_tm` (ntk2 base, logN). Same fields as above. Caveats: Exact-nonzero onset is early but tiny; the threshold onset supports 'acts from about step 8'. The note's '-0.57' reproduces on dev (ntk2 base, devtm_eta1: -0.57); held-out on the SEGA base gives -0.56. Only pairs 0-8 are ever corrected: the controller zeroes pairs whose wavelength exceeds the 256-token grid (crope/gain.py).
- **b1 (b) Released SEGA gains on Krea (held-out).** Source: `out_krea/main/sega_official/4096x4096/*.json` rows 8-194. Fields `gains[t].controller_log_g` (= 2 log q/k gain), `gains[t].official.reference_qk_gain`, `gains[t].official.spectral_spread`. Caveats: Decomposition of x = log g - log g_ref over (prompt, step, pair), sums of squares about 0 as in the CPU study; grand-mean centering moves each share by at most 0.003. 'Content' is the residual after the per-(step, pair) mean, so it includes each prompt's own noise draw (derived seeds differ by prompt). Seed 0 only. Released code (crope/sega_official.py allocation) maps pairs to profile bins by rank of log period, so no pair collapses to one bin; instead the longest-wavelength pairs sit at the clamp.
- **b2 (b) sega_ctm gains (held-out), released SEGA gain plus constancy_tm correction.** Source: `out_krea/main2/sega_ctm/4096x4096/*.json` rows 8-194. Fields `gains[t].controller_log_g` (total) and `gains[t].official_log_g` (SEGA part on the same trajectory). Caveats: eta = 1.0 (the variant that passed dev). The correction raises the prompt dependence of the allocation, yet the held-out result ties or loses.
- **c1 (c) Attention-gain transfer probe on Krea (dev prompts).** Source: `probe_krea/4096x4096{,_p1,_p2}/mtf.csv` column `response` = d log P_out / d log g_in, indexed by `domain`, `axis`, `input_bin` (0-5), `output_bin` (0-6); settings from `baseline/**/*.json` config. Caveats: Diag = mean of the 6 diagonal cells; Off = mean of the 36 off-diagonal cells of the 6 x 7 matrix (this reproduces the note's prompt-0 values exactly). Three dev prompts, one seed, one 1.5x same-seed finite difference per octave applied to both axes at once; ntk2 base with logN temperature (the constancy setting, not SEGA's). Latent width diagonal mean is 0.47 for prompt 0 but -0.03 and -0.04 for prompts 1 and 2, so the HANDOVER claim 'elasticity 0.1 to 1.7 on width' is a single-prompt result. Most latent diagonal cells are positive but small (14 and 16 of 18 for width and height); the large prompt-0 low-band values do not replicate, and prompts 1 and 2 show large negative low-band width responses.
- **c2 (c') FLUX.1-dev (lattice regime) versus Krea probe, prompt 0, factor 1.5.** Source: `probe/4096x4096/mtf.csv` (FLUX.1-dev) and `probe_krea/4096x4096/mtf.csv` (Krea), same fields; guidance from each `baseline/**/*.json` config. Caveats: Top band = input octave 5 (0.125-0.25 cycles per token). Krea diag and off for prompt 0 are the `NmechProbe*A` macros above. Not a pure checkpoint contrast: guidance (3.5 vs 4.5) and code revision (4d895a5 vs 09e07c2) also differ, and the sidecars do not record which transformer was loaded (identity comes from the directory and notes). FLUX.1-dev at 4096^2 is in the dot-lattice failure regime; one prompt, one seed.
- **d1 (d) CPU SEGA study, FLUX.2 VAE latents of DIV2K crops.** Source: `research_reviews/sega_2605.22668_2026-10-14/stats20.json` fields `N`, `C`, `L`, `real.R2_static_tilt`, `real.R2_time_only`, `real.content_share`, `generic_prior_vs_real_time_profile_corr`, `R2_real_explained_by_generic_prior`, `R2_sigma_time_only`, `R2_sigma_generic_prior`, `chanmean_power_fraction`, `dims_collapsed_to_lowest_bin`; `stats_4k.json` `dims_collapsed`, `R2_static`, `M_profile_late` (gain = M^2, first and last entries).
