\section{Methods under study}\label{sec:methods}

All arms share the sampler and differ only in $\omega'$ and $g$ of \cref{eq:fourier} (\cref{tab:knobs}); \cref{tab:methods} gives formulas, code revisions and sample sizes.

\paragraph{Frequency baselines}
\ntk{} is the strengthened NTK base that \sega{} builds on, $\theta'=\theta s^{2D/(D-2)}$, which divides the slowest pair's frequency by $s^2$; with no temperature and no allocation, it is the floor of the decomposition. \dype~\citep{issachar2025dype}, ported from the official code, blends position interpolation, NTK and native frequencies with two ramps in $\sigma^2$, so fine pairs regain their native frequencies late in denoising. Its cos/sin amplitude $1+0.1\ln s$ acts as a logit gain of $\N{c@dypegain}$ on the spatial dimensions.

\paragraph{\sega: paper equations and released code}
\sega~\citep{sega2026} sets per-pair gains from its input spectrum around $m_{\mathrm{ref}}=s^{0.08}$, giving more weight to low-energy pairs; \cref{alg:sega} gives the released update as we ported it. We call this parity-tested released port \segaofficial{} and our implementation of the printed equations \segapaper; the two differ at each of six compared stages (\cref{sec:papercode}).

\paragraph{\tempsb{} and the factorial}
\tempsb{} keeps the frequency base of \segaofficial{} and applies its reference logit gain $s^{0.16}=\N{c@segatemp}$ to every dimension. It differs from \segaofficial{} in three ways: no per-band shape, no lift in mean gain from the clamp at 1, and a gain of $s^{0.16}$ rather than 1 on the index axis. Two more arms complete a base-by-temperature factorial: \ntktemp{} applies the gain on the \ntk{} base, and \segabase{} keeps the released base without it.

\begin{algorithm}[t]
\begin{minipage}[t]{0.487\linewidth}
\algrule
\caption{\segaofficial, one gain update}\label{alg:sega}
\vspace{-3pt}\algrule[0.4pt]
{\footnotesize\textbf{Input:} projected input features $h$ on the $L_h\times L_w$ grid; frequencies $\omega_a$ of the released base; scale $s$.\\
\textbf{Output:} query/key gains $m$, one per rotary pair.}
\begin{lstlisting}[style=gold,emph={mean,flatness,radial_power,ones,axis_power,rank,log,interp,std,tanh,max}]
m_ref = s ** 0.08           # logit gain s^0.16
Z = mean(h, axis=channels)  # sensor, App. (*@\ref{app:impl}@*)
Z = Z - mean(Z)
spread = 1 - flatness(radial_power(Z)) ** 1.5
m = ones(64)                # index axis keeps 1
for a in (height, width):
    E = axis_power(Z, a)  # max(L_a//2, 8) bins
    r = rank(log(2*pi / w[a]))  # 0: fastest
    e = interp(log(E), (1 - r) * (K - 1))
    z = (e - mean(e)) / std(e)
    c = tanh(1.5 * z)
    c = c - mean(c)    # Sec. (*@\ref{sec:papercode}@*): 0.15, clamp
    m[a] = max(1, m_ref*(1 - 0.15*spread*c))
return m              # logits scale by m**2
\end{lstlisting}

\end{minipage}\hfill
\begin{minipage}[t]{0.487\linewidth}
\algrule
\caption{\constancytm, one gain update}\label{alg:ctm}
\vspace{-3pt}\algrule[0.4pt]
{\footnotesize\textbf{Input:} latent $x_t$ at noise level $\sigma$; previous clean estimate $\hat x_0$; native target $P(f,\sigma)$; $\eta=1$.\\
\textbf{Output:} query/key gains, one per rotary pair.}
\begin{lstlisting}[style=gold,emph={full,log,exp,band_energy,relu,P_native,mean,clip,interp_logf}]
log_g = full(64, 0.16*log(s))  # SEGA temp.
if x0_hat is None:             # step 0
    return exp(log_g / 2)
for a in (height, width):
    Et = band_energy(x_t, a)  # half octaves
    E0 = band_energy(x0_hat, a)  # App. (*@\ref{app:laws}@*)
    rho = relu(Et / (sigma**2 * C) - 1)
    w = rho / (1 + rho)    # visibility gate
    P = P_native(a, f_b, sigma)  # matched
    A = (f_b >= 1/64) & (f_b <= 1/16)
    c = mean(log(E0[A]) - P[A])  # anchor level
    e = 0.5 * (P + c - log(E0))  # Eq. ((*@\ref{eq:constancy}@*))
    d = eta * w * clip(e, -1, 1)
    # zero for pair wavelengths above L_a
    log_g[a] += interp_logf(d, f_pairs[a])
return exp(log_g / 2)          # q/k gains
\end{lstlisting}

\end{minipage}
\end{algorithm}

\subsection{Per-band laws from vision science}\label{sec:ours}

Contrast constancy keeps perceived band contrast nearly stable across viewing distances~\citep{georgeson1975contrast}. Efficient coding combines visibility against noise, $S/(S+N)$, with contrast normalization toward natural-image statistics~\citep{atick1990towards,atick1992retina,vanhateren1992theory,field1987relations,dong1995statistics,knill1990human,parraga2000human} and divisive gain control~\citep{webster2002neural,heeger1992normalization,schwartz2001natural,carandini2012normalization}. Four controllers build on them (\cref{app:laws}). \textbf{\constancy} weights a bounded log-power correction toward a native-resolution target by a noise-visibility gate, on the \ntk{} base with log-$N$ temperature. \textbf{\constancytm} (\cref{alg:ctm}) matches that target to the noise level and uses the base and temperature of \segaofficial{} (control: \tempsb). \textbf{\aliastemp} sets each pair's log-$N$ temperature from its resolvable key count, and \aliastemps{} matches \sega's reference geometric mean. \textbf{\segactm} adds the time-matched correction to \sega's allocation, $\ln g=\ln g^{\textsc{sega}}+\Delta$, with $\eta=1$ chosen on the dev set.
